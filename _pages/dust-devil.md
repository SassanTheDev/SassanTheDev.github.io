# Goals
Since the beginning, we wanted to make a casual, fun game inspired by Dune world and old retro twin stick shooter games. The game should be simple to learn and follow but with its own challenges.
# Challenges
The first challenge was the time. The scope of the project was bigger than I expected it but fortunately we could decrese development time by adding some pre made assets and plugins, most notably godot vehicle plugin.
I had to rewrite some parts of it for enemy cars so they chase the players and it turned out better than I expected.
The second challenge was the rendering issues with the sprites. The game has over 100 3D models in the same terrain. We had to remove the 3D model and use simple geometrical shapes while using pixelated filter to add retro feelings to the game.
